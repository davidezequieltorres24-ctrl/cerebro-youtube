# Checklist de lanzamiento

## Semana 0: setup
- [ ] Crear cuenta de Google exclusiva para el canal
- [ ] Crear canal "Cerebro Caro" y reservar el handle `@CerebroCaro`
- [ ] Logo + banner (Canva, ver `branding.md`)
- [ ] Descripción + links (próximamente: infoproducto)
- [ ] Instalar en Claude Code: Three.js + Remotion + skill de estilo
- [ ] Cuenta ElevenLabs: elegir 1 voz fija en español neutro (siempre la misma)
- [ ] Plantilla de miniatura (Photoshop/Canva) con la paleta y la fuente

## Semana 1: producción
- [ ] Guiones de los primeros 3 videos (verificados)
- [ ] Producir el video #1 completo → revisar → ajustar el estilo
- [ ] Producir #2 y #3 con el estilo ya fijo

## Semana 2: publicar
- [ ] Publicar 2 largos + 3 Shorts
- [ ] Responder TODOS los comentarios en las primeras 48 h
- [ ] Anotar en `contenido/publicados.md`: título, CTR, retención y aprendizaje

## Regla de iteración
- Después de 5 videos: mirar qué video tuvo el mejor CTR y la mejor retención → repetir esa promesa/formato.
- Cambiar 1 sola variable por video.
- Monetización (YPP): 1.000 subs + 4.000 h o 10M vistas de Shorts → activar AdSense.
